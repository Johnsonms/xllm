Second kernel task (started 2026-10-23, after TSDN in [[xllm-cute-tsdn]]): CuTe DSL kernels for AWM, replacing `xllm/modules/fused_ops/adaptive_working_memory.py` (`_adaptive_working_memory_fwd` / `_accum_fwd` / `_bwd`; the fused Gekko block calls the same three). Paper: arXiv 2601.06463 (Gecko), AWM = eq. (24); Gecko-7B trained 32K ctx, CP=2, 16K tokens/GPU.

**Real shapes (presets in xllm/models/gekko.py, C=4096):** gekko-0.9B H8 K4 S256 V256; gekko-4B H32 K8 S128 V128; gekko-7.1B H4 K4 S256 V2048. Training: ortho=False, segment_idx passed (int64 B x L, multi_segments=true), memory=None on CP rank 0 (rank>0 gets memory/prev from neighbour). AWM ~10% of step time (0.9B B2 L16K: fwd 1.4 + accum 1.3 + bwd 2.1 ms/layer; ~20x above HBM roofline).

**Harness:** scratch run_gekko.py <preset> <B> <L> (needs NCCL_SOCKET_IFNAME=lo NCCL_IB_DISABLE=1; stubs flash_attn_2_cuda; xllm_extension built into scratch/xext via setup.py build_ext with pip cu13 toolchain, ~4 min). Installed into ~/xllm-venv: fla-core + flash-linear-attention (--no-deps), typeguard, fire, sentencepiece, tiktoken==0.8.0, blobfile, submitit, nvidia-ml-py. gekko-4B OOMs at B1 L16K without FSDP/recompute.
